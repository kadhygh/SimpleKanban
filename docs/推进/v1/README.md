# v1 推进目录

这个目录用于集中管理所有与 `v1` 有关的文档。

## 阶段状态

- `v1` 当前实现阶段已完成验证与收口准备，可视为“准备结束”的历史阶段目录。
- 这里保留的是 `v1` 的实现记录、交接说明和阶段清单，不再作为后续新方向的主要承载目录。
- 自 2026-03-12 起，后续活跃规划请优先查看：
  - `docs/推进/v2/README.md`
  - `docs/推进/v2/修订版里程碑草案.md`

## 当前范围

v1 聚焦的不是完整 TaskCard 系统，而是先稳定打通以下最小闭环：

- 选择本地工程目录
- 创建网页托管终端会话
- 在网页中完成常规 terminal CLI 交互
- 注入执行器命令并观察状态
- 恢复当前终端会话状态

## 当前文件

- `docs/推进/v1/清单.md`：v1 的任务拆解与推进清单
- `docs/推进/v1/交接.md`：当前阶段的实现交接说明
- `docs/推进/v1/next-prompt.md`：下一次对话可直接复用的提示词
- `docs/推进/v1/TaskCard执行闭环里程碑.md`：TaskCard 接入终端执行闭环后的阶段性里程碑记录
