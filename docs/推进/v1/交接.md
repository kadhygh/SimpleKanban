## 1. 当前结论（已由你本人验证通过）

已完成并通过人工验证的当前节点：

- `M1`：本地服务 + 项目选择 + 持久化
- `M2`：网页终端（xterm.js + WebSocket + node-pty）最小闭环 + 页面刷新恢复
- `M4`：执行器模型（列表/预览/注入，单参数输入）
- `M5`：TaskCard 执行闭环（Run -> Terminal -> 状态回流）
- `M3`：会话可信性当前节点（服务重启：残留 `running/waiting` -> `lost`，避免“假运行”）
- `M6`：结构层当前节点（Task `dependencyIds` + 结构视图展示 + focus-only 子图）

当前仍保持的范围约束：

- 单机 / 单项目 / 单活跃终端（所有 TaskCard 共享一个活跃终端会话）
- 依赖关系仅用于结构展示，不做运行约束（但实现上保留未来加 gating 的扩展点）
- 产物层暂不做（后续有明确需求再加）
- 记忆层（memory）暂时封存（默认禁用）

下一最小节点（已拍板）：

- `M7 Canvas Spike`
- 目标是先验证“Task 投影到 canvas 后，是否比当前列表/结构混合页更适合作为主界面”
- 当前只做轻量节点投影、选中与联动，不做完整白板编辑器

## 2. 快速启动

在仓库根目录运行：

```bash
npm run dev
```

然后打开：

```text
http://127.0.0.1:3210
```

如果 `3210` 被占用（`EADDRINUSE`），可以改端口：

```powershell
$env:PORT=3211; npm run dev
```

## 3. 本地持久化（状态文件）

- 位置：`source/server/data/project-state.json`（已在 `.gitignore` 中忽略）
- 内容：`project`、`tasks`（以及启用 memory 时的 `memory`）

重置方式：

1. 停止服务。
2. 删除 `source/server/data/project-state.json`（或清空文件内容）。
3. 重新执行 `npm run dev`。

## 4. 环境变量

- `HOST`：监听地址，默认 `127.0.0.1`
- `PORT`：监听端口，默认 `3210`
- `PTY_SHELL`：指定 PTY 启动 shell
- `SIMPLEKANBAN_ENABLE_MEMORY`：`1` 表示启用 memory（当前默认封存且未接 UI）

补充说明：

- Windows 默认 PTY shell 是 `powershell.exe -NoLogo`；
- 非 Windows 默认使用 `$SHELL`，否则回退到 `bash`；
- v1 当前没有把 memory 暴露为 API，也没有把它接入 UI。

## 5. 关键数据结构（当前实现口径）

### 5.1 Project

```json
{
  "name": "SimpleKanban",
  "path": "D:\\Projects\\SimpleKanban",
  "updatedAt": "2026-03-11T00:00:00.000Z"
}
```

### 5.2 Task

字段（主要）：

- `id`, `title`, `description`, `executorId`
- `status`: `idle | running | waiting | lost | ended`
- `dependencyIds`: `string[]`
- `linkedSessionId`: `string | null`
- `lastRunAt`, `lastStatusAt`, `lastTerminalActivityAt`, `lastTerminalOutput`
- `attachments`: 目前支持 `note`（备注）类型

状态语义：

- `idle`：未运行
- `running`：已触发运行（命令已写入共享终端）
- `waiting`：检测到需要人工输入/确认（启发式基于终端输出关键字）
- `ended`：终端会话已关闭/结束
- `lost`：服务重启后无法确认之前运行的终端会话，标记为丢失，需要手动重新运行

### 5.3 TerminalSession

`GET /api/terminal/session` 返回的会话快照包含（主要字段）：

- `id`, `projectPath`, `cwd`, `shell`, `pid`, `cols`, `rows`
- `status`: `starting | running | closed | error`
- `createdAt`, `startedAt`, `endedAt`, `lastOutputAt`, `exitCode`, `error`

## 6. API 概览

- `GET /api/health`
- `GET /api/project/current`
- `POST /api/project/select`：空 body 会弹 Windows 目录选择器；也支持传 `{ "path": "D:\\\\Projects\\\\X" }`
- `GET /api/executors`
- `POST /api/executors/preview`
- `POST /api/executors/inject`（或 `POST /api/executors/run`）
- `GET /api/terminal/session`
- `POST /api/terminal/close`
- `GET /api/tasks`
- `POST /api/tasks`
- `POST /api/tasks/run`
- `POST /api/tasks/dependencies`
- `POST /api/tasks/note`

## 7. 关键代码位置

服务端：

- `source/server/server.mjs`：HTTP API + WS + Task 运行与状态回流
- `source/server/lib/project-store.mjs`：Project/Task 持久化、M3 reconcile、（封存的）memory 结构
- `source/server/lib/terminal-session-manager.mjs`：单活跃终端会话（node-pty）
- `source/server/lib/executor-profiles.mjs`：执行器注册表、参数规范化与命令拼装
- `source/server/lib/folder-dialog.mjs`：Windows 目录选择器

前端：

- `source/web/index.html`
- `source/web/app.js`
- `source/web/styles.css`
- `source/web/canvas.html`
- `source/web/canvas.css`
- `source/web/canvas.js`
