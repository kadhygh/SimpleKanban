# 推进目录说明

这个目录用于存放项目推进过程中的阶段性文档。

## 目录约定

- `v1/`：存放所有与 v1 相关的文档
- `v2/`：存放围绕“结构化 AI 工作台”重构后的对象模型、视图模型和新里程碑草案
- 后续如果进入新阶段，可以继续增加：
  - `v3/`
  - `research/`
  - `records/`

## 当前规则

- 与 v1 需求、任务拆解、接口设计、实现记录、问题清单、验收标准有关的内容，统一放在 `docs/推进/v1/`。
- 与 v2 规划、对象模型重构、工作台视图设计和多 session 路线有关的内容，统一放在 `docs/推进/v2/`。
- `docs/dashboard.md` 用来展示全局推进状态。
- `prepare.md` 用来承载当前阶段的总体准备方案，不负责记录日常推进细节。

## 当前入口

- `docs/推进/v1/README.md`
- `docs/推进/v1/清单.md`
- `docs/推进/v2/README.md`
- `docs/推进/v2/修订版里程碑草案.md`

## 当前阶段说明

- `v1` 当前已经完成“本地服务 + 网页终端 + 执行器 + TaskCard + 结构视图 + Canvas Spike”这一轮验证，进入准备收束阶段。
- `v2` 当前用于承接新的工作台方向：以 `TaskCard`、`DocCard`、`Session` 为核心对象，以 `CanvasWorkspace` 和 `ListWorkspace` 为主要视图。
- `CanvasWorkspace` 的首要职责是帮助开发者观察、理解和调度，而不是默认作为 session 内 LLM 的完整上下文来源。
- 当前优先级已经切换为：先明确对象模型与多 session 路线，再考虑完整终端历史和更完整的白板交互。
